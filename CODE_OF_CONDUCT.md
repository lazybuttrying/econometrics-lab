# Code of Conduct

This project follows the Contributor Covenant 2.1 spirit.

## Expected behavior
- Be respectful and constructive.
- Assume good intent.
- Give actionable feedback.

## Unacceptable behavior
- Harassment, intimidation, or discrimination.
- Personal attacks or bad-faith engagement.
- Publishing private information without consent.

## Enforcement responsibilities
Maintainers are responsible for clarifying and enforcing community standards.

## Scope
Applies to project spaces (issues, PRs, discussions) and public representation of the project.

## Reporting
Report concerns to maintainers via GitHub issues/discussions with private details minimized.

## Enforcement ladder
1. Correction
2. Warning
3. Temporary restriction
4. Permanent ban for severe/repeated violations
