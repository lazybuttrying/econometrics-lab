# Security Policy

## Supported versions
Current support target: `main` branch only (early stage).

## Reporting a vulnerability
Please report privately to maintainers first (do not open a public issue with exploit details).

## What not to disclose publicly
- Exploit steps
- Sensitive logs or credentials
- Unpatched vulnerable paths

## Response timeline
- Acknowledge within 72 hours
- Provide status update within 7 days

## Proof-of-concept handling
Share minimal PoC needed for verification; avoid destructive payloads.

## Dependency hygiene
Keep dependencies updated, review advisories, and use CI checks before release.
