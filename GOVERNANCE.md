# Governance

## Roles
- Maintainer: roadmap, review, release ownership
- Reviewer: quality checks and feedback
- Contributor: proposes and implements changes

## Decision process
Default is lazy consensus. If blocked, maintainers apply tie-break decision.

## Change categories
- Minor docs: fast-path review
- New experiments: reproducibility + tests required
- Architecture changes: design discussion first

## Deadlock escalation
If discussion stalls, open a summary issue and request maintainer decision.

## Adding maintainers
Active contributors with sustained high-quality reviews and delivery may be invited by existing maintainers.
