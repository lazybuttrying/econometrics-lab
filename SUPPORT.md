# Support

## Where to ask questions
- GitHub Discussions: how-to questions, learning threads, design ideas.
- GitHub Issues: reproducible bugs and scoped feature requests.

## Issue vs discussion
Open an issue when behavior is wrong or an actionable task is defined.
Use discussions for open-ended questions.

## What to include
- Goal
- What you ran
- Expected vs actual outcome
- Relevant logs/snippets

## Reproducibility failures
Tag as reproducibility issue and include seed, data path, and exact command.

## Response time
Best effort by maintainers; triage happens weekly.
