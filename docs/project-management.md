# Project Management Guidance

## Label usage
Use domain labels (`concept`, `experiment`, `src`, `tests`, `docs`, etc.) plus one priority label.

## Milestone usage
Every issue should map to exactly one milestone aligned with roadmap phase.

## Priority policy
- `priority:high`: needed for current milestone progress.
- `priority:medium`: important but schedulable.
- `priority:low`: backlog and optional work.

## Triage cadence
Weekly async triage every Monday; update labels, milestones, and acceptance criteria.

## Ready for contribution criteria
- Task is scoped and bounded.
- Acceptance criteria are explicit.
- Labels and milestone are assigned.
