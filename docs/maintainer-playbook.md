# Maintainer Playbook

## Weekly triage checklist
- Review new issues/discussions
- Ensure labels + milestones
- Reprioritize blocked work

## Stale issue handling
Comment with unblock request, then close stale items after grace period.

## Release readiness checklist
- CI green
- Concept gate green
- Changelog updated
- Release notes drafted

## Contributor recognition
Thank first-time contributors and highlight merged contributions monthly.

## Conflict resolution basics
Use evidence, restate options, and escalate to maintainer tie-break when needed.

## Quality gate reminders
Enforce seed usage, relative paths, reusable code, and tests.
