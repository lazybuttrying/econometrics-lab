# Triage Guide

## Category rubric
- bug
- docs
- experiment
- feature
- question

## Severity and priority
Map impact/urgency to `priority:high|medium|low`.

## Labeling flow
Apply one domain label + one priority + support labels as needed.

## Milestone flow
Assign issue to nearest roadmap milestone.

## Close vs keep open
Close when duplicate/out-of-scope/resolved; keep open when actionable with acceptance criteria.
