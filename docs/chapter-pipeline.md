# Chapter Pipeline

Chapter lifecycle:
1. Concept pages drafted
2. Questions recorded
3. Simulations implemented
4. Visualizations generated from code
5. Experiments completed and interpreted
6. Reusable functions extracted to `R/`
7. Interactive/project integration
8. Reflection completed

Mandatory outputs per chapter:
- Concept pages in `concepts/`
- Experiment directories in `experiments/`
- Reusable code in `R/`
- Tests in `tests/testthat/`
- Reflection file in `reflection/`
- Knowledge graph updates in `knowledge/graph.md`

Templates:
- `templates/concept-template.md`
- `templates/chapter-template.md`
- `templates/qmd-analysis-template.qmd`
- `templates/experiment-template/`
