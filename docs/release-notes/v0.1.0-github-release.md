# v0.1.0 — Foundation Release

This release introduces the first contributor-ready scaffold for **econometrics-lab**.

## Highlights
- Repository architecture for concepts, experiments, reusable code, and reflections
- Reproducible workflow with Quarto rendering, testthat tests, and concept-gate checks
- Seeded random-variable concept and central-limit-theorem experiment
- Governance and onboarding docs for new contributors

## Start instructions
1. Clone the repository
2. Install dependencies listed in README
3. Run CLT experiment
4. Render the first report
5. Run tests
