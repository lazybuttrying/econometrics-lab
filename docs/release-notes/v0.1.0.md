# v0.1.0 Release Notes

## What this release establishes
v0.1.0 sets up a reproducible foundation for learning econometrics through concepts, experiments, reusable code, and reflection.

## Highlights
- Full scaffold for concepts, experiments, templates, docs, and governance.
- First seeded concept set and CLT experiment.
- CI checks for linting, tests, and concept gate compliance.

## Who this release is for
- Self-learners who want a structured econometrics workflow.
- Contributors who want clear templates and contribution paths.
- Educators building practical econometrics examples.

## Known limitations
- Several concept and experiment areas are scaffolds pending deeper implementation.
- Interactive projects are placeholder-level at this stage.

## What’s next (v0.2.0 goals)
- Expand probability/statistics concept coverage.
- Add LLN and sampling-distribution experiment implementations.
- Strengthen tests and plotting conventions.
