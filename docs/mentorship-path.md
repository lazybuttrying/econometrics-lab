# Mentorship Path

## Newcomer track
- Competencies: run repo, open first issue/PR
- Tasks: docs fixes, concept template fill
- Progression: one merged PR + reproducible commands
- Labels: `good first issue`, `docs`, `concept`

## Builder track
- Competencies: implement experiments and tests
- Tasks: experiment scaffolds, helper extraction
- Progression: two merged feature PRs with tests
- Labels: `experiment`, `src`, `tests`

## Reviewer track
- Competencies: code review and reproducibility checks
- Tasks: review PRs, triage issues, improve guidance docs
- Progression: consistent high-quality reviews
- Labels: `help wanted`, `ci`, `refactor`
