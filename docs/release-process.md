# Release Process

## Versioning
Use semantic versioning in `0.y.z` phase:
- `y`: feature milestones
- `z`: fixes and small improvements

## Changelog process
Update `CHANGELOG.md` with Added/Changed/Fixed before tagging.

## Release checklist
- [ ] CI passing
- [ ] Concept gate passing
- [ ] Docs updated
- [ ] Release notes drafted

## Tagging convention
Use `v0.x.y` tags.

## Post-release verification
Confirm release artifacts, links, and quickstart commands still work.
