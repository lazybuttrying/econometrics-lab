# Social Preview Guidance

## Recommended dimensions
Use 1280x640 (or 1200x630) PNG.

## Suggested text overlay
- Title: Econometrics Lab
- Subtitle: Reproducible econometrics by building concepts + experiments

## Branding guidance
Use high-contrast text, simple visual motif (graph/plot), and repository name.

## How to set in GitHub
Repository Settings → General → Social preview → Upload image.
