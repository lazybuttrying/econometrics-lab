# Community Cadence

Async-first norms: default to written updates, record decisions in issues/docs.

## Weekly (suggested Monday/Wednesday)
- Monday: issue triage and reprioritization
- Wednesday: review window focus
- Friday: discussion prompt post

## Biweekly (suggested Tuesday)
- Newcomer onboarding thread with curated good-first issues

## Monthly
- Release
- Retrospective
- Roadmap update

## Quarterly
- Strategy review and milestone reset
