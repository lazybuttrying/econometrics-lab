# Contributor Funnel

Objective: first PR in < 7 days.

| Stage | Activation trigger | Friction points | Interventions | Success metric |
|---|---|---|---|---|
| Visitor | Finds README | Unclear value | Strong mission + quickstart | README-to-issue clicks |
| Reader | Opens docs | Too many choices | Start-here path | Discussion/issue comments |
| Issue commenter | Leaves question | Slow responses | Weekly triage replies | % comments with maintainer reply |
| First PR | Picks issue | Scope uncertainty | Good-first issues with checklist | First PRs/month |
| Repeat contributor | Merges once | Recognition gap | Contributor shout-outs | Repeat contributors/month |
| Reviewer | Understands codebase | Confidence barrier | Reviewer playbook | External review count |
